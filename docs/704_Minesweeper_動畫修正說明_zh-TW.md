## 二、企畫書原有需求

依企畫書兩頁內容，原始動畫與操作需求如下：

1. 前導第一段：`Wall Left` 需要有地雷造型按鈕，觸發後像踩中地雷一樣向外擴散；待機背景跟著擴散圈逐步變黑，整段約 5 秒。
2. 前導第二段：浮現特大英文標題 `Cybercube Minesweeper`，停留後以動畫退場。
3. 前導第三段：主遊戲待機畫面由地板 `PLAY` 按鍵所在場景 fade in 進場，正式進入主遊戲待機。
4. 前導限制：fade in 尚未完成時，踩到 `PLAY` 不應立即觸發；若玩家已站在 `PLAY` 區域，需離開後重新踩入才算觸發。
5. 超時結尾：顯示 `TIME OUT` 與紅色波紋；地板的揭露／標記按鈕融合成一個繼續按鈕，按下後才開始結尾動畫。
6. 過關結尾：最後一格揭露後擴散金色波紋，地板顯示 `You Win`；所有地板按鈕先消失，再 fade in 半透明 mask 覆蓋全場，並保留地板上的 `You Win`。
7. 成績畫面：牆面格子逐格消失，全部消失後全場變黑；接著 `Wall Left` fade in 成績與 `Thank you for playing`，文字需大且方便拍照。
8. 後台操作：玩家拍照並離場後，後台可按一個按鈕讓遊戲回到外部待機畫面。
9. 中途離場：移除 `ABORT`，保留 `PAUSE`；暫停時仍照常計算時間，若到達 `TIME OUT`，仍進入超時結尾。

企畫書流程圖另標示「待機畫面」、「教學」與「遊戲中」為已完成項目。本輪不重新設計或製作教學，只在分鏡中標出 `PLAY` 的操作閘門；`PLAY` 觸發後仍銜接既有教學／倒數／遊戲流程。

## 三、本次正式整合的修正內容

以下修正已同步標入分鏡圖並加入遊戲：

1. **啟動來源**：後台「開始遊戲」先進入 `armed`；玩家按下 `Wall Left` 地雷造型按鈕後，才啟動前導；波紋起點為按鈕正中心。
2. **前導閘門**：外部 `idle`、`armed` 與前導／fade in 期間鎖定其他場域觸控，完成後才開放 `PLAY`。
3. **超時閘門**：`TIME OUT` 與紅色波紋完成後，才顯示合併後的 `CONTINUE`；按下後才進入結尾。
4. **過關閘門**：結尾與成績畫面完成前不顯示、不接受 `RETURN`；完成後才可返回。
5. **中途離場**：只保留 `PAUSE / RESUME`，不提供 `ABORT`；暫停期間仍持續計時。
6. **流程節點參考值**：前導約 5 秒；超時紅色波紋約 1.8 秒，收束後保留約 400ms 閘門才開放 `CONTINUE`；按下 `CONTINUE` 後播放約 6.2 秒超時結尾，結尾完成後才進入 `RETURN`。
7. **前導切換方式**：前導尾段的主遊戲待機、`PLAY` 預覽與各視圖底層需持續 fade in；不可在 5 秒節點硬切。前導遮罩在進入 `ready` 前淡至透明。
8. **結尾遮罩時序**：過關／超時結尾都先完成半透明 mask 的覆蓋，再開始牆面格子逐格消失；全數消失並進入全黑後，才淡入成績畫面。
9. **多視圖同步**：Cyberpunk 全展開視圖、`all` 視圖、地板視圖與各牆面視圖共用同一組流程節點與操作閘門；畫面可各自取景，但不可各自提前顯示 `PLAY`、`CONTINUE` 或 `RETURN`。

### 1. 啟動權與視覺起點拆分

- 啟動流程由後台控制台先行解鎖：工作人員確認場地、投影與感應設備完成後，按下「開始遊戲」。
- 後台按下後只進入 `armed`，玩家仍須按下 `Wall Left` 地雷造型按鈕，才正式進入前導。
- 外部 `idle` 待機不提供可由玩家踩入的開始入口，場域觸控保持鎖定。
- 為保留企畫書的空間敘事，實際視覺波紋仍從 `Wall Left` 的地雷造型位置開始；也就是「控制權在後台，視覺起點在 Wall Left」。
- 這保留企畫書要求的玩家實體按鈕觸發，同時讓後台擁有每局的啟動／中止控制權。

### 2. 前導期間完整鎖定場域操作

- 後台啟動後先進入 `armed`，等待玩家按下 `Wall Left` 地雷按鈕；按鈕觸發後才進入約 5 秒前導。
- 波紋擴散、標題浮現與主遊戲待機畫面淡入期間，玩家踩踏均不改變流程。
- fade in 完成後才進入 `ready`；玩家若先站在 `PLAY` 區域，仍需離開後重新踩入。

### 3. 超時後增加明確的操作閘門

- 時間到先演出 `TIME OUT` 與紅色波紋。
- 波紋完成後，地板操作合成並顯示 `CONTINUE`。
- 只有玩家按下 `CONTINUE` 後，才開始超時結尾動畫；超時畫面本身不會自動跳過等待。

### 4. 過關後增加明確的結尾閘門

- 最後一格觸發金色波紋與 `YOU WIN`，之後依序進行按鈕消失、全場半透明遮罩、牆面逐格消失、全黑與 `Wall Left` 成績淡入。
- `RETURN` 在結尾動畫與成績畫面準備完成前不出現，也不接受觸控。
- 成績畫面完成後才開放 `RETURN`，按下後回到外部 `idle` 待機。

### 5. 暫停規則維持企畫書方向

- 遊戲中只保留 `PAUSE`／`RESUME`，不提供 `ABORT`。
- 暫停只改變畫面與場域操作狀態，時間限制仍持續計算。
- 暫停期間到時，仍按照超時分支演出：`TIME OUT` → 紅色波紋 → `CONTINUE`。

### 6. 時間與定位的分鏡標註

- 前導時間以約 5 秒作為分鏡節點，包含 `Wall Left` 波紋擴散、待機背景變暗、標題浮現與主遊戲待機 fade in。
- 超時分支以「紅色波紋約 1.8 秒 → 約 400ms 操作閘門 → 顯示 `CONTINUE` → 按下後超時結尾約 6.2 秒 → `RETURN`」呈現。
- `Wall Left` 的波紋起點使用地雷按鈕幾何正中心 `(352, 1696)`；正式投影校正前，仍需以實體投影驗收。
- 上述秒數與座標只用來確認流程節奏與視覺起點，尚未定義最終作畫、easing、設備延遲或現場校正值。

### 7. 補充修正：視圖一致性與遮罩時序

- **前導尾段不硬切**：主遊戲待機底層與 `PLAY` 預覽在前導最後一段逐步 fade in；5 秒只代表前導節點完成，不代表畫面要瞬間替換。
- **遮罩先完成再消失**：過關或超時進入結尾後，先讓半透明 mask 覆蓋全場並穩定，再開始牆面格子逐格消失。遮罩尚未完成時，不提前清除牆面格子。
- **地板訊息保留**：過關時地板操作按鈕先消失，`YOU WIN` 留在地板；mask 覆蓋後仍保留該訊息，直到流程進入全黑／成績階段。
- **視圖同步**：`all` 與各單面視圖都要看到同一流程的對應節點；前導期間即使看得到 `PLAY` 預覽，也不可接受觸控，必須等閘門開放後才有效。

### 8. 結尾時序修正（加入本版分鏡）

以下是為了把「先遮罩、再消失、最後成績」變成可核對的分鏡節點而加入的實作時間。時間從按下 `CONTINUE`（超時）或觸發過關結尾（過關）起算；企畫書原文沒有指定這些秒數，現階段視為可由現場校正的參考常數。

| 結尾時間 | 分鏡節點 | 必須成立的畫面條件 |
|---|---|---|
| `0.00s` | 結尾開始 | `TIME OUT`／`YOU WIN` 與對應波紋已完成前置觸發；地板操作按鈕依分支清除 |
| `2.36s` | mask 開始明顯覆蓋 | 半透明 mask 由透明淡入，全場仍保留原有牆面格子 |
| `3.10s` | mask 完成覆蓋 | mask 達到穩定覆蓋狀態；在此之前不得開始牆面格子消失 |
| `3.20s` | 格子消失開始 | 牆面格子依序開始消失，第一批與 mask 完成保留約 `100ms` 間隔 |
| `3.20-3.70s` | 消失延遲散佈 | 不同格子依序錯開開始，最大散佈延遲約 `0.50s` |
| `5.50s` | 全場全黑 | 最後一批牆面格子完成消失；全黑狀態先穩定，不提前顯示成績 |
| `5.55s` | 成績淡入 | `Wall Left` 成績與 `Thank you for playing` 才開始淡入；文字仍需保留大字、易拍照 |
| `6.20s` | 結尾節點完成 | 結尾動畫時間參考完成；此後才可進入 `RETURN` 的可操作狀態 |

這個時序特別修正了兩個容易誤解的地方：

- `mask` 不是和牆面格子同時開始；必須等到 `3.10s` 完成覆蓋後，才在 `3.20s` 開始逐格消失。
- 成績不是在格子消失過程中浮現；必須等到約 `5.50s` 全黑，再於約 `5.55s` 後淡入。

### 10. V3.3 本輪新增修正

#### 10-1. 所有結算顯示必須在實體場域正向可讀

本項以使用者提供的 `TIME OUT` 結算截圖作為構圖參考：中央主標題清楚、左側成績板可讀、中央返回動作清楚。截圖是視覺參考，不是取代企畫書的操作指令。

「正向」定義為：玩家站在場域內、面向該面牆時，英文標題、成績欄位、`THANK YOU FOR PLAYING`、`CONTINUE`、`RETURN` 都不可左右反轉、上下顛倒或側躺。判定基準是**投影到實體牆面後的觀看方向**，不是 `all` 展開圖裡的文字方向。

驗收範圍：

| 實體區域 | 過關結算 | 超時結算 | 正向驗收重點 |
|---|---|---|---|
| Wall Top | `YOU WIN`、結算資訊 | `TIME OUT`、結算資訊 | 站在場內看，文字水平且由左至右 |
| Wall Left | 成績板、`THANK YOU FOR PLAYING` | 成績板、`THANK YOU FOR PLAYING` | 成績板是拍照主畫面，欄位需由上至下可讀 |
| Wall Button | 結算主標題／狀態 | 結算主標題／狀態 | 不因牆面位於下方而倒置 |
| Wall Right Big | `YOU WIN` 或狀態提示 | `TIME OUT` 或狀態提示 | 站在場內看不可側躺 |
| Wall Right little | 可放縮短版狀態提示 | 可放縮短版狀態提示 | 面積不足時可減少內容，但保留正向方向 |
| Floor | `YOU WIN`、`RETURN` | `TIME OUT`、`RETURN` | 玩家從場內接近地板時仍可直接辨識 |
| `all`／Cyberpunk | 全場構圖預覽 | 全場構圖預覽 | 只作流程與構圖檢查，不作實體旋轉的唯一判定 |

目前 `wallprojector-template/projections.json` 的 rotation 只能視為初始值，不能直接宣告已驗收。後續製作前要逐一開啟 `wall-top`、`wall-left`、`wall-button`、`wall-right-big`、`wall-right-little`，以實際投影觀看方向確認；若任一面出現側躺或倒置，應在投影設定調整，不在分鏡中用展開圖方向掩蓋問題。

#### 10-2. 後台加入「結束遊戲 · END GAME」

- 位置：後台 `GAME SETUP` 控制區；不加入地板，也不加入任何玩家可踩的場域按鈕。
- 可用時機：只要 phase 不是 `idle` 就可按，包括 `intro`、`ready`、`tutorial`、`tutorialReady`、`countdown`、`playing`、`paused`、超時結尾、過關結尾與成績畫面。
- 行為：按下後立即清除本局 timer、結尾動畫與操作閘門，直接回到外部 `idle` 待機。
- 回到 `idle` 後：棋盤重新初始化、場域觸控鎖定、清除 `PLAY`／`CONTINUE`／`RETURN` 與結算遮罩；後台重新顯示 `開始遊戲`。
- 不等待：不需要等 `TIME OUT`、`YOU WIN`、逐格消失或 `RETURN` 播放完成。
- 場域規則：維持企畫書修正，玩家端不恢復 `ABORT`；`END GAME` 是後台專用控制。

分鏡上，A2 的 `END GAME` 代表一條可從所有非 `idle` 節點直接返回外部待機的旁路，不是只在成績畫面才出現。

#### 10-3. 前導標題上牆，擴散起點改為地雷按鈕正中心

- `CYBERCUBE MINESWEEPER` 必須出現在實際牆面內容區，尤其是 `Wall Left` 的牆面表面；不可只在 `all`／中央空白區顯示。
- 擴散起點定義為 `Wall Left` 地雷造型按鈕的**幾何正中心**。
- 不採用 `Wall Left` 整面中心、不採用展開圖中心，也不沿用舊稿的暫用整面中心座標。
- 製作時應先建立命名錨點 `WALL_LEFT_MINE_BUTTON_CENTER`，再由所有 view 依同一個場域座標換算顯示；不能每個 view 各自猜一個起點。
- 目前按鈕版位為 `Wall Left` board col `4..6`、row `15..17`，場域座標正中心為 `(352, 1696)`；所有 view 由 server snapshot 的 `startButton` 共用。

前導分鏡節點：

| 節點 | 畫面要求 | 驗收方式 |
|---|---|---|
| A3-1 | 地雷按鈕亮起，第一圈從按鈕中心出現 | 圈心與按鈕中心重合，不是牆面中心 |
| A3-2 | 擴散圈向場域外擴散，待機背景同步變暗 | `all` 與各牆面 view 使用同一場域起點 |
| A4 | `CYBERCUBE MINESWEEPER` 貼在牆面內容區浮現 | 單獨開 `wall-left` 也能看到標題，不依賴中央總覽 |
| A5 | 標題退場、主遊戲待機 fade in | `PLAY` 閘門仍依原 V3.2 規則開放 |

### 11. V3.4 本輪新增修正

#### 11-1. TIME OUT 的 Floor 與 Entrance 維持乾淨底色

使用者提供的畫面顯示，`TIME OUT` 期間 Floor 出現大面積紅／黑分割，Entrance 也出現不明顯色帶；這些效果看起來不像有意義的結算動畫，容易被判定為投影或 mapping 錯誤。

V3.4 將 V3.2「紅色效果延伸至整個場域」的寬泛做法收斂如下：

- 牆面棋盤區可以保留設計好的紅色波紋、紅色格子反應與 `TIME OUT` 結算內容。
- Floor 只保留中央 `TIME OUT` 面板、受控的紅色波紋／光暈與閘門後的 `CONTINUE`；底層維持乾淨的深色，不出現左右切半的紅色大色塊。
- Entrance 是非互動、非棋盤區；`TIME OUT` 時維持黑／中性底，不套用紅色棋盤格、不套用整片紅色 wave fill，也不出現無法說明來源的矩形色帶。
- 若未來需要讓 Entrance 顯示狀態，只能使用明確設計的小型狀態提示，不得用整面染色取代內容。
- `all` 展開圖只能作為整體構圖參考；Floor／Entrance 是否乾淨，仍要以各自的 `floor` 與 Entrance 投影取景確認。

驗收條件：

| 區域 | TIME OUT 可保留 | 必須移除／禁止 |
|---|---|---|
| Floor | 中央 `TIME OUT`、受控紅色波紋、`CONTINUE` | 整片紅底、左右半邊色塊、紅色棋盤格、無來源矩形遮罩 |
| Entrance | 黑／中性底、必要時的小型狀態提示 | 紅色棋盤格、整片紅色 wave、突兀紅色或其他未定義色帶 |
| 牆面棋盤區 | 設計好的紅色波紋與結算訊息 | 不應把非棋盤區的色塊誤延伸到 Floor／Entrance |

#### 11-2. 最後分數面板整體逆時針 90°

- 作用對象：`Wall Left` 最後成績面板的**整個群組**。
- 需要一起旋轉的內容：外框、`TIME OUT`／`YOU WIN` 標題、`THANK YOU FOR PLAYING`、時間、標記地雷數、揭露格數與所有欄位文字。
- 變換方向：以目前面板設計座標為基準，整體逆時針 `90°`（`CCW 90°`）。
- 不可只旋轉文字，也不可只旋轉外框；面板內所有元素要保持相對位置一起轉。
- Floor 上的 `RETURN` 是獨立的地板操作，不屬於 Wall Left 分數面板群組。
- 旋轉完成後仍要以玩家站立方向檢查一次，避免和 WallProjector 的面向 rotation 疊加造成二次旋轉。

本項在 B4 分鏡中以「`SCORE PANEL GROUP: ROTATE CCW 90°`」標示；目標不是讓展開圖看起來正，而是讓實體場域中的 Wall Left 成績面板正向可讀。

## 六、目前正式流程

目前正式流程為：

`外部待機（純色背景＋粒子、無場域開始入口） → 後台按開始遊戲 → armed（Wall Left 地雷按鈕亮起） → 玩家按下地雷按鈕 → 從按鈕正中心向外擴散約 5 秒 → 標題浮現 → 待機與 PLAY fade in → 重新踩入 PLAY 才開始 → 原有遊戲流程 → 超時紅波紋 1.8 秒／閘門 400ms／按 CONTINUE → 結尾約 6.2 秒（mask 2.36-3.10s → 格子 3.20s 起 → 5.50s 全黑 → 5.55s 成績）→ 完成後按 RETURN 回待機`

正式整合採用後台「開始遊戲」作為每局啟動的第一道閘門，再由玩家按下企畫書中的 `Wall Left` 地雷按鈕觸發前導。所有場域輸入與結尾動作都由 server 閘門控管，各視圖只負責依同一時間戳呈現。

目前流程已使用 `WALL_LEFT_MINE_BUTTON_CENTER`，並具備後台 `END GAME → 外部 idle` 的全狀態旁路；接下來只需實機確認投影 rotation 與感應範圍。

目前未包含在本次範圍內的項目：投影機與感應器的現場校正、最終音效、最終字體與正式部署排程。
